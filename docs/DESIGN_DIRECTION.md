# LaserX Design — Premium Website Design Direction

## Quality target

This website must look and feel like a custom $20,000+ industrial design and manufacturing website, not a generic local contractor template.

The visual standard should be comparable to premium engineering, automation, architecture, and advanced-manufacturing firms.

## Brand position

LaserX Design is not presented as only a welding or plasma-cutting service.

It is a design-and-build company combining:

- SolidWorks and AutoCAD
- product and machine design
- CNC plasma cutting
- custom fabrication
- fixtures and manufacturing systems
- machine wiring and controls
- sensors and automation
- prototype development
- complete machine building

## Visual direction

- Dark, refined industrial palette
- Large editorial typography
- Strong spacing and grid discipline
- CAD drawings, machine details, welds, wiring, and finished equipment used as primary visual material
- Subtle technical overlays, linework, dimensions, and blueprint references
- Smooth restrained motion, never gimmicky animation
- High-contrast calls to action
- Mobile layouts designed intentionally rather than simply stacked

## Experience goals

Visitors should immediately understand that LaserX Design can take an idea from concept through CAD, fabrication, wiring, controls, assembly, and a working finished system.

The site should create confidence through proof:

1. Real projects
2. Detailed case studies
3. Clear process
4. Technical capability
5. Strong visual presentation
6. Honest, grounded copy

## Required page architecture

- Home
- About
- Services
- Projects / Case Studies
- Individual project pages
- Process
- Contact / Request a Project

## Homepage structure

1. Premium full-screen hero with real project imagery or video
2. Strong positioning statement
3. Capability overview
4. Featured CNC plasma table case study
5. Design-to-build process
6. Selected projects
7. Technology and software capabilities
8. About Chris Hilton / founder credibility
9. Strong project inquiry section

## Case study standard

Each major project should include:

- project challenge
- design constraints
- CAD and engineering work
- manufacturing and fabrication
- wiring, controls, or automation where applicable
- photos and technical visuals
- final outcome
- lessons or improvements

## Non-negotiables

- No generic construction-site appearance
- No fake testimonials
- No invented certifications or customer claims
- No low-quality stock photography as the primary identity
- No excessive gradients, glowing effects, or template animation
- No public personal phone number or home address without explicit approval
- Original user photos must never be regenerated or altered without explicit permission
