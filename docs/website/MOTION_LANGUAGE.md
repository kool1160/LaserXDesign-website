# LaserX Website Motion Language

LaserX motion should feel like a precision fabrication cell, not a generic animated marketing site.

## Core rule

**Rapid travel → controlled deceleration → locate → lock.**

Motion is part of the LaserX identity. Navigation stays simple; the presentation carries the drama.

## Signature behaviors

- Hero content enters from opposite axes and locks into the first viewport.
- Major sections index into place instead of fading normally.
- A thin positioning rail sweeps across each major station as it locks.
- The physical 3D section assembles from separated layers.
- Manufacturing-repair metrics arrive in sequence so the problem → safe repair → human decision story reads visually.
- Header navigation uses a short shutter/index transition before positioning the next station.
- A restrained page-axis indicator reinforces the machine metaphor without becoming navigation.

## Restraint

Do not animate every paragraph, icon, or small control. Large motion is reserved for major product moments so it remains meaningful.

Do not use:

- neon gamer effects;
- random floating particles;
- fake holographic HUDs;
- long blocking intros;
- confusing custom navigation;
- motion that delays access to information.

## Accessibility and performance

- Respect `prefers-reduced-motion`.
- Keep navigation usable without the motion layer.
- Prefer CSS transforms, opacity, clipping, and small browser-native scripts.
- Do not load a 3D engine solely for website transitions.
- Keep the first screen fast on mobile.

## Brand intent

A visitor should remember that the LaserX website itself moved with the precision and weight of a machine.

The motion can be bold. The interface must remain obvious.
