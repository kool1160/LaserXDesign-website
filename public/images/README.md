# LaserX Design image library

## Live site assets

- `hero/` — homepage hero photography
- `projects/x-series-1/` — X Series 1 project and CAD-to-machine visuals
- `capabilities/fixtures/` — fixture and tooling visuals
- `capabilities/controls/` — controls, wiring, and integration visuals
- `capabilities/cad/` — CAD and engineering visuals
- `our-process/x-series-1/` — generated process artwork for the X Series 1 story
- `about/` — future shop, builder, and company-story photography

## Intake and archive

- `uploads/` — temporary intake folder for newly uploaded images
- `library/generated/` — unassigned generated images kept by source set
- `archive/illustrations/` — retired SVG concepts retained for reference

Use descriptive lowercase filenames with hyphens. New images should enter through `uploads/` unless a section-specific folder has already been assigned.
